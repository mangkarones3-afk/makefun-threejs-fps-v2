YARDLINE: SODIUM RAIN — an original round-based tactical FPS built with three.js: 5v5 Breachers vs Wardens on an original container-yard map, with a buy-phase economy, six weapons plus grenades, bot teammates and opponents, and a plant/defuse breach-charge objective. Fully offline, zero network requests.

Sodium Rain commits the yard to one mood: a rain-slick night under sodium floodlights. Falling rain and drifting cloud, volumetric lamp cones and hot light pools on wet asphalt, gloss puddles, a working gantry crane swaying its load over mid, procedurally textured container steel (ribs, rust, fleet stencils), modelled soldiers with chest rigs, helmets and lit team strips, soft shadows under ACES tone mapping, tracer fire with impact sparks and dust, full explosion effects — and a juice pass throughout: hit-stop on kills, a slow-motion round-end beat, kill banners, screen shake, FOV kick, weapon sway and a pulsing low-health vignette.

## Run it

```sh
node main.ts
```
